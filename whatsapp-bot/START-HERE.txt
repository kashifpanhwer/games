────────────────────────────────────────────────────────────────────
 🅰️  VPS / HOSTING PAR  (Ubuntu, Debian, CentOS — sabse aasan)
────────────────────────────────────────────────────────────────────

  1. ZIP upload karein (FileZilla, cPanel File Manager, ya scp se)

  2. Extract karein:
         unzip KashifTechAdvanceBot.zip
         cd whatsapp-bot

  3. Ek command:
         bash deploy.sh

     Ye script khud:
       • Node 20 + ffmpeg install karegi
       • npm install karegi
       • .env banayegi aur aapse NUMBER poochegi
       • network check karegi (doctor)
       • poochegi ke bot kaise chalana hai (PM2 / systemd / Docker / nohup)

  4. Pairing code dekhne ke liye:
         pm2 logs kashif-bot              (agar PM2 chuna)
         journalctl -u kashif-bot -f      (agar systemd chuna)
         docker logs -f kashif-bot        (agar Docker chuna)
         tail -f logs/bot.log             (agar nohup chuna)

     Ya seedha:
         curl -s "localhost:3000/api/pairing?token=YOUR_TOKEN"

  5. Phone par:
         WhatsApp ▸ Settings ▸ Linked Devices ▸ Link a Device
         ▸ "Link with phone number instead"
         ▸ 8 character ka code type karein

  6. Control panel browser mein:
         http://YOUR_SERVER_IP:3000/?token=YOUR_TOKEN
     (agar na khule to firewall mein port 3000 allow karein: ufw allow 3000/tcp)


────────────────────────────────────────────────────────────────────
 🅱️  WINDOWS PC PAR
────────────────────────────────────────────────────────────────────

  1. Node.js install karein:  https://nodejs.org  (LTS version)
  2. ZIP extract karein, folder mein jayein
  3. CMD ya PowerShell kholein us folder mein
  4. Chalayein:
         npm install
         npm run doctor      ← network check, zaroor chalayein
         npm run pair        ← pairing code aayega


────────────────────────────────────────────────────────────────────
 🅲  TERMUX (ANDROID PHONE) PAR
────────────────────────────────────────────────────────────────────

  1. Termux install karein — F-DROID se, Play Store wala purana hai:
         https://f-droid.org/en/packages/com.termux/
  2. Termux kholein aur chalayein:
         pkg install -y git unzip
  3. ZIP ko phone mein daalein, phir:
         cd /sdcard/Download
         unzip KashifTechAdvanceBot.zip
         cd whatsapp-bot
         bash scripts/install-termux.sh
  4. IMPORTANT — warna Android bot maar dega:
         • Termux notification ▸ "Acquire wakelock"
         • Settings ▸ Apps ▸ Termux ▸ Battery ▸ Unrestricted

════════════════════════════════════════════════════════════════════
 ⚠️  ZAROORI BAATEIN
════════════════════════════════════════════════════════════════════

  1. PAIRING CODE WhatsApp ka server deta hai, ye bot nahi banata.
     Isliye jis machine par bot chalega, uska internet WhatsApp tak
     pahunchne ke qabil hona chahiye. Check karne ke liye:
         npm run doctor
     Agar "TLS handshake" par ✖ aaye to us machine ka network blocked hai.

  2. Code sirf ~60 second rehta hai. Expire ho jaye to:
         npm run pair        (naya code)
     Ya panel mein "🔄 Request new code" dabayein.

  3. SHARED HOSTING (cPanel / Hostinger shared plan) PAR BOT NA CHALAYEIN.
     Wo lambe processes ko maar dete hain. VPS, Render/Railway, Docker,
     ya Termux use karein.

  4. Number format:  923145396910   (03145396910 NAHI)
     deploy.sh aur install-termux.sh khud convert kar dete hain.

  5. sessions/ folder = aapki login credentials. Kisi ko na dein,
     git mein commit na karein. Delete karne se dobara pair karna padega.

  6. .env file mein PANEL_TOKEN default "kashiftech" hai. deploy.sh
     khud random token bana deta hai — manual install par badal lein.
